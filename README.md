## 订阅前值得知道的几个坑

**“额度大”不等于无限。** SuperGrok 走的是 Fair Use 机制，短时间连续生成图片或视频可能触发软限流，停一会儿会自动恢复。真遇到额度卡住，可以在 grok.com 或 X 上联系 @grok 请求手动重置，不少用户反馈成功率不低。

**网页端和 App 要用同一个账号。** 网页用 Google 登录、手机用 Apple 登录，会被系统当成两个账号。App 里提示“需要升级”，多半不是会员失效，是登错号了。多设备切换没问题，但别频繁换登录方式，更别多人共用——官方条款不允许共享账号凭据。

**中国区 App Store 搜不到 Grok。** 官方 App 没在中国区上架，想用手机 App 得换区，或者干脆用网页版——网页版功能其实最全。

**拼车合租便宜，但风险也实在。** 多人共用一个账号，聊天记录、额度、登录状态互相影响，而且违反平台条款，翻车了很难有像样的售后。真要选这条路，先把质保范围、售后期限和退款条件问清楚。

**破解版别碰。** SuperGrok 的会员权限存在 xAI 服务器端，改客户端改不掉任何东西。网上那些“免费解锁全部功能”的页面，不是套壳就是钓鱼，交出去的是你的密码和聊天记录。
